Wiko Laygunata - 2802417945
Website html biasa dengan menggunakan tailwind css

## Menjalankan website

Website ini static HTML. Buka `index.html` langsung di browser; tidak perlu menjalankan server, `npm install`, atau `npm run`. File CSS hasil build sudah tersedia di `assets/tailwind.css`.

## Mengubah styling Tailwind

Perintah npm hanya diperlukan jika mengubah class Tailwind di HTML dan ingin membangun ulang CSS:

```sh
npm install
npm run build:css
```

Setelah build, website tetap dijalankan dengan membuka `index.html`.
